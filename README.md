# 🎨 SmartPaint – Smart Wall Paint Visualizer

> A full-stack MEAN application that helps users visualize wall paint colors on their room images before making a painting decision.

SmartPaint is an interactive **Smart Wall Paint Visualizer and Paint Shopping Platform** built using the **MEAN Stack**. It allows users to explore paint colors, view different shades, upload room images, select wall areas, preview colors, compare designs, save their favorite colors, add paint products to a cart, and place orders.

The application combines **room visualization, color exploration, authentication, shopping cart functionality, and order management** into a single platform.

# 📌 Project Overview

Choosing the right wall color can be difficult because users often cannot imagine how a particular color will look in their actual room.

SmartPaint solves this problem by allowing users to:

- 🏠 Upload their room image
- 🎨 Explore different paint colors
- 🖌️ Select wall areas
- 🌈 Apply different colors to the selected wall
- 👀 Preview the room before painting
- 🔄 Compare Before/After designs
- ❤️ Save favorite colors
- 🛒 Add colors/products to cart
- 💳 Proceed through checkout
- 📦 Place and track orders
- 👤 Manage their account
- 🛠️ Manage colors, prices, stock and orders through an Admin Panel

The goal is to provide a simple and interactive experience for users who want to experiment with wall colors before purchasing paint.
